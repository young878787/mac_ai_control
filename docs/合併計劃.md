**喚醒詞規則**

| 情況 | 例子 | 行為 |
|---|---|---|
| 句首是喚醒詞，後面接指令 | 「露醬，打開小算盤」 | 去掉喚醒詞和後面的標點，剩下的「打開小算盤」送去執行 |
| 只說喚醒詞 | 「露西婭」，停頓後再說「打開小算盤」 | 進入待命 **8 秒**，期間的下一句不用喚醒詞就會執行；執行一次後待命結束 |
| 沒有喚醒詞，或喚醒詞不在句首 | 「我跟露醬說…」 | 不執行，終端以灰字顯示「（未喚醒）…」 |

另外兩點：
- **比對方式：** 先去掉空白和標點、統一大小寫，再比對句首。比對清單是標準寫法加上誤聽變體，簡體寫法（露西娅、露酱）也在清單裡。只做精確比對，不做模糊比對，避免誤觸發。
- **喚醒詞的資料放在 `vocab/lexicon.json`**，新增一個欄位：
  ```json
  "wake_words": {"names": ["露西婭", "露醬", "露西亞"],
                 "misheard": [{"text": "露西雅", "source": "seed"}, {"text": "露西娅", "source": "seed"},
                              {"text": "露酱", "source": "seed"}, {"text": "Lucy", "source": "observed"},
                              {"text": "西亞", "source": "observed"}, {"text": "的路線", "source": "observed"}]}
  ```
  `names` 會寫進 `stt_hints.txt`，讓辨識引擎偏向這三個詞；`misheard` 不寫進去，沿用既有的「不強化錯誤寫法」原則。
