# 0013 fullrig03 定版模型；CPU 5% 指整台電腦；Electron 路線甲

- 狀態：採用
- 日期：2026-11-20
- 來源：[桌面角色模型升級（fullrig03）](../plans/completed/2026-11-20-fullrig03-model.md) §2 A1～A7、§3.3～3.5

## 背景

新模型多了 43 個參數、19 組物理、4 個表情。完整流程 60 fps 實測佔單核 37.5%。成本主要是 Chromium 每出一幀的固定成本（透明視窗只清畫面、60 fps 就要 20.9%），不是模型本身。原生 Swift＋Metal 只畫一個方塊也要 7.7～8.3% 單核。

## 決定

1. 以 `Rushia_hd/runtime-fullrig03` 為定版模型，模型檔不修改（A1）。
2. 有畫面在動時一律穩定 60 fps；潛伏時頭髮物理收尾就停格（0 fps）（A3、D5）。
3. CPU 目標 5% 的單位是**整台電腦**（8 核 M1，等於單核 40%）（A6）。
4. 走路線甲：Electron＋渲染優化（O1 GL buffer、O2 狀態快取、O5 Core 以 30 Hz 計算再內插到 60 fps，逐項 A/B 實測，有效才保留）＋潛伏停格。
5. 新表情與動作接進狀態機；手臂類表情放在獨立的手勢層，避免蓋掉臉部表情。Talk 動作沒有聲音也可以用（A5）。

## 後果

- 結案時出場峰值在門檻附近浮動（單核 38.1～42.0，門檻 40），沒有穩定達標；要再降只能犧牲畫質，需要使用者決定。
- 量測用 `scripts/ui_perf.py`，同一時段的前後比較才有意義。
